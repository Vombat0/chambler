## Yapilanlar
1. `packages/shared/src/transformCodec.ts` (yeni, sifir bagimlilik):
   - Paket: 1 B tip + 1 B kayit sayisi + N x 40 B kayit (uint16 indeks, 3xfloat32 konum,
     4xint16 kuaterniyon, 3xfloat32 hiz, uint16 seq, uint32 t).
   - `TransformIdTable` (kalici id<->indeks, indeks yeniden kullanilmaz), `isNewerSeq` (uint16 wrap),
     `unwrapTimestamp` (uint32 -> mutlak ms), `quatAngleDegrees`, `distance3`.
   - Hassasiyet sozlesmesi dosya basinda: konum/hiz float32 (<=1.2e-7 goreli, |x|<=1000 icin <=0.12 mm),
     rotasyon bilesen hatasi <=1/65534, aci hatasi <=0.0036 deg.
2. `packages/client/src/net/TransformSender.ts` (yeni): hareket filtresi (0.5 mm / 0.1 deg),
   20 Hz hizli / 5 Hz yavas / durunca tek stop frame, kare basina 64 nesne butcesi,
   kuyruk tasmasinda en eski kare atilir, nesne basina uint16 seq.
3. `packages/client/src/net/NetBridge.ts`: cikis artik `transformBatch` (ikili); giris
   `transformBatch` cozulup interpolator'a veriliyor; `dieResult` gonder/al; eski JSON
   `transformUpdate` okuma yolu korundu.
4. `packages/server/src/rooms/BandwidthBudget.ts` (yeni): oda bayt butcesi (varsayilan 64 KB/s,
   `TRANSFORM_BUDGET_BYTES_PER_SEC`), oyuncu basina esit kota, adil kirpma, 1 sn pencere, sayaclar.
5. `packages/server/src/rooms/dieResult.ts` (yeni, saf): zar yuzu sayisi (meta.faces/sides, varsayilan 6),
   1..yuz dogrulama, sahiplik, ayni claim epoch icinde celiskili sonuc reddi (1.5 sn pencere).
6. `packages/server/src/rooms/TableRoom.ts`: `transformBatch` al/coz/kota/kuyruk, 50 ms'de bir
   (varsayilan) istemci basina filtrelenmis tek paket flush (sahibine geri gonderilmez), eski JSON
   yolu korunuyor (deprecated), `dieResult` kalici state + yayin + reconnect/late-join replay,
   `getMetrics()` sayaclari.
7. `packages/server/src/rooms/ObjectState.ts`: `netIndex`, `dieValue`, `dieRolledBy`, `dieRolledAt`.
8. `packages/server/scripts/bandwidth.ts` + `package.json` `bandwidth` script.

## Acik kararlar / sapmalar
- Hedef "10-20x"in alt ucu (10.5x). Nedeni: 40 B kayit fiziksel taban (spesifikasyon 3xfloat32 hiz
  istiyor), JSON tarafi msgpack ile zaten 233 B'ye iniyordu (271 degil). Daha fazlasi icin hiz alaninin
  int16'ya inmesi veya 5 Hz tabaninin dusurulmesi gerekir; ikisi de kapsam disi birakildi.
- Eski JSON yolu kaldirilmadi: hem B2 testleri aynen gecsin hem de "once" olcumu gercek kod uzerinden
  yapilsin diye deprecated olarak korundu.
- Sahibine kendi frame'i geri gonderilmiyor (istemci basina filtre) -> ~%12 daha az cikis.
- `ObjectEvents.emitTransformUpdate` (A3 dosyasi) tum nesneler icin TEK global 20 Hz kelepce kullaniyor;
  ayni anda birden fazla nesne suruklenirse ornekleme sinirlanir. Sahiplik disi oldugu icin dokunulmadi,
  oneri: kelepce nesne basina olmali.
- Lint'te 3 hata `packages/client/src/inspect/**` (A6 dosyalari) — benim degil, dokunulmadi.
