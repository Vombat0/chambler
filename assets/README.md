# Asset Directory

This directory contains assets for the Tabletop Simulator-style game.

- dice/ - dice models and textures
- pawns/ - pawn models and textures
- tokens/ - token models and textures
- cards/ - card models and textures
- tiles/ - tile models and textures
- board/ - board models and textures
- textures/ - general textures (fabric, wood, felt)
- audio/ - sound effects and music
- ui/ - user interface elements

Each asset is licensed under CC0-1.0 and sourced from the listed providers. No branded content is used.
