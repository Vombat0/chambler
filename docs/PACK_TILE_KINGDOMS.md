# Tile Kingdoms — game pack (C5)

Tile-laying + worker-placement pack on the **square snap grid** (A5). 24 original
tile types, 72 tiles in one draw bag, 5 worker colours × 7 followers.

## Contents

- `manifest.json` — derived by `scripts/build-manifest.ts`; never hand-edit.
- `board/board.json` — grid type **square**, 23×23 cells, cell 1×1, start cell
  (11,11). Edge contract references `packages/client/src/grid/TileEdges.ts`.
- `tiles/tiles.json` — every type with `edges {north,east,south,west}` over
  `city | road | field | shrine`, a `centre` feature and a bag count.
  `start-capital` is the single marked start tile.
- `rules/rules.json` — rules as data: road 1 pt/tile, city 2 pt/tile (+2 per
  pennant, +2 Great Keep), shrine 9 pts when ringed by 8 tiles, fields score
  3 pts per completed city per farmer at the end.
- `tokens/workers.json` — roles Gözcü/Watchman (road), Muhafız/Guard (city),
  Keşiş/Monk (shrine), Çiftçi/Farmer (field); colours ember, lagoon, moss,
  plum, sand.
- `i18n/tr.json`, `i18n/en.json` — identical key sets (91 keys).
- `assets/` — all art generated by `scripts/generate-art.ts` (PNG + SVG twins,
  every file > 1 KiB, sha256-indexed in `art-index.json`). Nothing is downloaded.

## A5 integration

Tile components carry `defaultMeta.edges` exactly in the shape the client's
`TileEdges.checkEdges`/`rotateTileEdges` consume: equal facing values match,
rotations 0/90/180/270. `manifest.board` exposes grid + cellSize + a
`start-cell` snap point at (11.5, 0, 11.5).

## Build & validate

```bash
cd packs/tile-kingdoms
pnpm run art:local && pnpm run manifest:local   # regenerate
node ../../packages/modkit/dist/cli.js .        # → OK
pnpm run test:local                             # 43 tests
```

## Originality

"Tile Kingdoms / Kare Krallıklar" is an original theme: original names, texts
and code-drawn art. Only the genre mechanics (draw, edge-match, place a worker,
score features) are shared; no third-party names, logos or artwork are used.
